# 🚀 AI Data Analyst App

An intelligent CSV analysis tool that allows users to upload datasets and query them using natural language.

---

## ✨ Features

* 📂 Upload CSV files
* 🤖 AI-powered insights (Groq/OpenAI)
* 📊 Interactive charts (bar, line, pie)
* 💬 Natural language Q&A
* 📜 Query history tracking

---

## 🛠 Tech Stack

* Frontend: React.js
* Backend: Flask (Python)
* AI: LLM (Groq / OpenAI)
* Data Processing: Pandas

---

## 📊 Demo Dataset

👉 [Download Sample CSV](./data/demo_sales.csv)

Try queries like:

* "Total sales by city"
* "Top selling product"
* "Revenue by category"

---

## ⚙️ Installation

### Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend

```bash
cd frontend
npm install
npm start
```
